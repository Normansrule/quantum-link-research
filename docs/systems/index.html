Systems engineering · needs → requirements → tests

Every requirement points at the test that proves it.

This is a systems-engineering thesis, so the physics is organized the way a system is: stakeholder needs, requirements traced to them, trade studies that choose the architecture, risks, and a verification for every requirement. The matrix below is systems/traceability_matrix.csv; a requirement counts as verified only if its named test exists and passes in CI.
