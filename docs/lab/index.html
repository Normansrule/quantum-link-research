Each lab shows the real build in 3D with every part placed where it stands and paid for by a line of the bill of materials, the parameters that matter as sliders, and a terminal that prints the exact math, line by line, from the same formulas the Python test suite checks. MAIN EXPERIMENT

The two-room link

Starter bright-light analogue ($40–120) → single photons between two rooms ($530–1,180) → avalanche-diode upgrade → entangled photons. Weak 405 nm pulses, decoys, four SiPMs, FPGA gating, and a fiber classical channel, with the twin's prediction for every knob.
