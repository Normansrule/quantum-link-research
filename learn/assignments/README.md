# Assignments

Problem sets for the course in [`../COURSE_SYLLABUS.md`](../COURSE_SYLLABUS.md). Each set has numerical answers that a script checks against the repository's functions, so an instructor can grade by running `python -m pytest tests/test_assignments.py`; a student can check their own work the same way after filling in `answers.py`. Written parts are graded by the rubric in the syllabus.

| Set | Weeks | Topic | Numerical items | Written items |
|---|---|---|---|---|
| [PS1](ps1_qubits_and_temperature.md) | 1–3 | qubits, noise, temperature | 4 | 2 |
| [PS2](ps2_entanglement_and_teleportation.md) | 5–6 | Bell tests, teleportation, light time | 4 | 2 |
| [PS3](ps3_links_keys_memories.md) | 9–11 | loss, keys, memories, purification | 5 | 2 |
