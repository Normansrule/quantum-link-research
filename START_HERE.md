# Start Here

1. **Read the top of the [README](README.md)**: the goal (communication as close to instantaneous as physics allows, anywhere, and secure), what the project is, what is implemented (and what is only modelled or planned), and the development status. The advanced Earth–Mars, repeater, and memory studies are research models; they are further down the README and are not prerequisites for anything below.
2. **Pick one of three paths** (results are labelled SIMULATED, VERIFIED SOFTWARE, MEASURED HARDWARE, or FUTURE RESEARCH)
   - **Send messages offline.** Read [program document 11](systems/program/11_healing_network.md), then run the mesh model (`qll/link/mesh_messenger.py`) and the banked-key messenger (`python -m qll.link.banked_messenger --help`).
   - **Explore quantum science.** Follow the [README quickstart](README.md#run-a-simulation): create the Conda environment, run `python scripts/check_env.py`, then `python -m qll.link.run session`. A seeded run is reproducible; it is not secret.
     Then open the [website](https://normansrule.github.io/quantum-link-research/), or serve it offline with `python -m http.server --bind 127.0.0.1 --directory docs 8000`. For the concepts behind them, use the [learning guide](learn/README.md).
   - **Build the quantum testbed.** Read [P10](experiments/protocols/P10_two_room_single_photon_link.md) and its [evaluation specification](experiments/specs/two_room_evaluation_spec.md). P10 is a planning document: its build status is BLOCKED until a qualified laser-safety review is recorded, and its FPGA timing system is planned, not implemented. Stage 0 (simulation) and Stage 1 (the authenticated classical channel) need no optics.
3. **Check the evidence before relying on a number.** The tests badge on the README is written by the CI run that built the deployed website; the counts in [docs/status.md](docs/status.md) are an inventory. The [audit findings matrix](docs/audit/2026-10-11_findings.md) records what was fixed, what was tested, and what is still blocked.
4. **Want to work on the project?** Start from a failing test or a row in [`research/thesis/BACKLOG.md`](research/thesis/BACKLOG.md), and follow [CONTRIBUTING.md](CONTRIBUTING.md).

Three rules you will see everywhere: nothing signals faster than light (`ClassicalMessage` refuses early reads), nothing is cloned, and teleportation costs two classical bits. Three files you will come back to: [`learn/00_GLOSSARY.md`](learn/00_GLOSSARY.md), [`docs/physics_overview.md`](docs/physics_overview.md), and [`docs/physics_module_design.md`](docs/physics_module_design.md).
