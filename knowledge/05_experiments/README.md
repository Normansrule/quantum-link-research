# Experiments: done, proposed, and the lessons between them

Three sub-folders, one template.

- `done/` — landmark experiments, each with: **Original** (who, when, what was measured), **Physics** (the equation being tested), **Simple recreation** (what a student lab or a simulation can do, at what cost), **What went wrong historically** (the iterations before it worked), **Repo hook** (the `qll` module or test that carries it).
- `proposed/` — experiments nobody has run that would move the Earth–Mars concept of operations forward, each with a cheap version, a research version, and the traceability row it verifies. E1–E7 are also summarized in `docs/hardware_and_experiments_guide.md` §6; E8–E10 are new.
- `lessons/` — contested, retracted, or over-claimed results, and what scaled versus what did not.

The order to attempt the recreations on a student budget: ODMR (`done/04`) → Rabi/Ramsey/echo (`done/05`) → Hong–Ou–Mandel (`done/06`) → SPDC Bell test (`done/03`) → single-photon interference (`done/02`) → then the software-only recreations of everything else.
